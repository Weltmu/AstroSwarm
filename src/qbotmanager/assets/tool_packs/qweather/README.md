# 和风天气能力包

让 AI 自动查询城市实时天气（温度 / 天气现象 / 风 / 湿度 / 气压 / 能见度等）。

## 安装后配置（必须）

本工具使用和风天气 JWT（Ed25519）认证，需要三样配置：

1. **API Host**：和风控制台 → 设置 → API Host（形如 `xxx.qweatherapi.com`，
   不要带 https://）。
2. **项目ID**：和风控制台 → 项目管理，项目 ID。
3. **凭据ID**：控制台 → 项目管理 → 点进项目 → 添加凭据 →
   身份认证方式选「JSON Web Token」→ 粘贴公钥 → 保存后显示的凭据 ID。
4. **ed25519 私钥**：星群程序的插件页「生成密钥对」会自动生成并保存私钥，
   公钥直接复制到控制台即可；也可以在 https://jwt.qweather.com 生成。

配置入口：桌面端「插件 → 已装能力包 → 配置」；
Linux 无头端「插件 → 工具（能力包）→ 和风天气配置」。

配置保存后**重启机器人**生效。机器人进程会通过
`QWEATHER_API_HOST` / `QWEATHER_PROJECT_ID` / `QWEATHER_CREDENTIAL_ID` / `QWEATHER_PRIVATE_KEY_PATH`
三个环境变量把配置传给工具。

## 说明

- 只支持城市实时天气；台风路径 / 太阳辐射 / 海洋类数据不在范围内，
  agent 被问到时会如实解释。
- 免费版 API Key 从 2027-01-01 起每日限 1000 次，JWT 不限，所以默认走 JWT。
