【任务】星群官网（astroswarm.cn）改版：从"单一产品介绍页"改成"多产品个人站"

一、背景与目标
- 域名不变，继续用 astroswarm.cn。
- 现在的官网只讲"Windows 平台的 AI 机器人部署（星群）"，但我后面产品会越来越多，官网要变成"作品站"：首页先讲人（我）和我做的东西，然后每个产品一张卡，点进去是独立介绍页 + 下载页。
- 已知产品：
  1. 星群 AstroSwarm —— Windows 桌面端 + Linux 无头端，本地跑 QQ/微信机器人，AI 大脑（DeepSeek 等），AI 插件工坊，群记忆 / 主动聊天 / 群管理 / 小游戏。代码全开源。
  2. 恋爱小站 —— 网页产品，还在做，后期上站，先把位置和结构预留出来。
  3. 以后还会有更多产品，结构要能"加一行就多一个产品"，不要每加一个产品就改一次页面代码。

二、必守规则（跟客户端那个会话协作）
- 改服务器 /opt/qbot_website 前先跑 bash /opt/qbot_website/.coord/site_fingerprint.sh check；改完在 /opt/qbot_website/.coord/handover.md 文末只追加一行（时间/谁/改了哪些文件/为什么/如何回滚），不要改历史行；然后跑 site_fingerprint.sh snapshot；JS 改动先本地 node --check；最后 curl 验证线上 200。
- download.html / apps.html / about.html 里的版本号和安装包链接归客户端会话维护，这两类内容你不要动；需要改就在 handover.md 里留言。
- index.html 和 space/* 归你。
- 共享仓库 D:\ai\QBotManager\_website，git 提交前先拉取看有没有新提交。
- 客户端仓库 D:\ai\QBotManager、开源仓库 D:\ai\AstroSwarm-public 不要动。

三、商业口径（很重要，别写错）
- 星群客户端代码（含微信通道代码）全部开源免费；插件也全部免费。
- 微信通道官方提供"开通 + 部署 + 维护"的收费服务，用户也可以照文档自己搭。所以话术是"代码全开源，自己接也行；官方帮你开通和后续维护要收费"，不要出现"付费解锁功能 / 付费会员 / 尊享"这类字样。
- apps.html 里嵌的桌面端截图还印着"付费解锁 ClawBot 通道 / 付费解锁更多能力"，这些图要换掉。需要哪些截图、什么尺寸、每个产品几张，请你列一份清单给客户端会话，由客户端重拍/重出。

四、结构建议（设计可自由发挥，但请保留要点）
- 首页：一句话说清"我是谁、我在做什么" + 产品卡片区 + 最新更新 + 下载入口。
- 产品页：每个产品一个独立介绍页（说清这是干嘛的、给谁用、怎么装、收不收费），URL 走子路径（如 /astroswarm、/love-station），不要开子域名。
- 下载页：不要再"一个产品写一段 HTML"。改成用一份清单文件驱动（建议 /downloads/manifest.json），每个产品一行：id、名称、图标、一句简介、版本号、各平台安装包链接、校验值、更新时间。官网和客户端检查更新都读这份清单，以后加产品只加一行。
  - 请把 manifest 的字段格式定下来发客户端会话，客户端按它对接到软件里的"检查更新 / 下载"。
- 插件商店：全部免费，去掉价格和会员相关元素。
- 教程 / 文档区：装机教程、常见问题（FAQ）。
- 关于 / 联系：接单、定制、售后联系方式。

五、文案要求
- 去掉 AI 味：不要"赋能 / 一站式 / 极致体验 / 重新定义"这类词，用大白话，像跟朋友介绍自己在做什么。
- 不要"付费会员 / 解锁 / 尊享"字样。
- 讲清限制（用户一定会踩坑）：
  - 插件工坊是沙箱运行：不支持第三方库、长连接（WebSocket / MQTT / 直连数据库）、常驻后台进程、任意文件读写、系统命令；联网由主程序代发（只允许公网 http/https，单次 ≤20 秒、返回 ≤2 万字）；单次工具调用总时长上限 15 秒。
  - 微信通道只能在 30 分钟内主动发消息；QQ 官方接口没有"群成员禁言"。
- 所有页面手机端要能正常看（很多用户从抖音点进来）。

六、你要回给客户端会话的东西
1. manifest 字段格式（定稿）。
2. 页面结构 / 菜单分级（一级菜单别超过 5 个）。
3. 需要客户端提供的素材清单（截图、图标、尺寸、每个产品几张）。
4. 你改了哪些文件的清单（写进 handover.md）。
