# 插件工坊使用说明（大白话版）

## 一句话

想给机器人加功能，不用找人写代码：打开「插件工坊」，用大白话说你想要什么，
AI 会先给你方案，你点一下生成，程序自动检查、自动试跑，通过后点安装就行。

> 位置：侧栏「能力」→「插件工坊」。

## 三步用起来

1. **配模型（只配一次）**
   点右上角「配置生成模型」，填服务商 + API Key + 模型名。
   只支持有编码能力的强模型：DeepSeek / ChatGPT / Claude / 智谱 GLM / 通义千问 / Kimi。
   这里的配置和「AI 大脑」的模型完全分开、互不影响。

2. **说需求 → 看方案**
   比如「群里谁签到就记一次，能查每个人有多少金币」。
   点「让 AI 出方案」，它会用大白话告诉你：要做什么、需要什么权限、能在哪些通道用。

3. **生成 → 安装 → 重启机器人**
   点「生成插件」，程序会自动：
   - 检查代码结构和语法；
   - 检查有没有用不该用的东西（偷看文件、偷偷联网）；
   - 在沙箱里试跑一遍（不会真的发消息）；
   - 有问题自动让 AI 改，最多改 2 遍。
   全绿后点「安装到机器人」，再点「重启机器人生效」。

## 为什么它是安全的

- **只能在沙箱里跑**：生成的插件在独立进程里执行，碰不到你的文件、系统命令和其他插件的数据。
- **动作要过审**：插件想发消息、写记忆、联网，必须先在 `manifest.json` 里声明权限，
  而且真正的动作由主程序执行：动作白名单 + 权限 + 当前通道三重校验，失败会如实报错。
- **联网受限**：联网只能走 `http_request` 动作，只允许 http/https 公网地址，
  内网地址（127.0.0.1 / 192.168 等）一律拒绝。
- **说错话不会发生**：插件只返回结构化数据，怎么说给用户听由 agent 按人设组织。

## 什么情况下插件会"用不了"

| 情况 | 原因 |
|---|---|
| 群里没反应，私聊却能用 | 插件声明的通道里没有群聊（比如微信只能私聊） |
| 让机器人禁言，它说做不到 | QQ 官方接口没有群成员禁言能力；只有机器人是管理员且接口支持才行 |
| 微信提醒没发出来 | 微信主动消息只有 30 分钟窗口，用户太久没说话就发不出去 |
| 装了但没生效 | 还没重启机器人（点「重启机器人生效」） |

## 卸载与回滚

- 「已装的插件」列表里选中插件 →「卸载选中的插件」（旧版本会留档，不是直接删掉）。
- 想换回上一版 →「换回上一版」。
- 每个插件最多保留 5 个历史版本，都在安装目录 `workshop/history/<插件id>/` 下。

## 分享给别人 / 传到插件市场

「已装的插件」下面有一排按钮：

| 按钮 | 干什么 |
|---|---|
| 导出 zip | 把插件打包成一个 zip。发给朋友后，对方在工坊里点「导入插件包」就能装 |
| 导入插件包… | 装别人给的 zip。会先跑一遍完整检查（语法 / 危险调用 / 沙箱试跑），不合格直接拒绝，不会把来路不明的代码装进机器人 |
| 上传到官网审核 | 用星群账号把插件传给站长。**站长在官网审核台点「通过」之后才会进插件市场**，所有用户都能一键装；被驳回会写原因，改完可以再传 |

上传用的是「设置 → 星群账号」里登录的那个账号，没登录会提示你先登录。
审核状态在「上传到官网审核」的结果里能看到（审核中 / 已上架 / 被驳回 + 原因）。
官网上的入口是 `https://astroswarm.cn/plugin-upload.html`，同一页里站长还能下架已上架的社区插件。

## 插件跑挂了：让 AI 按报错修一版

前面的自动检查只能挡住"跑不起来"的插件；真实群里还会遇到参数不对、接口改版这类问题。所以：

- 工坊生成的插件在真实使用中报错时，程序会自动把「哪个插件 / 哪个工具 / 完整报错」记下来
  （文件在 `<机器人根>/workshop/runtime_errors.json`，最多 40 条）；
- 插件列表会显示「跑出过 N 次错」，选中它点 **「让 AI 修一版」**；
- AI 按真实报错改完之后，仍然要过一遍静态检查 + 沙箱试跑，全绿才让你点安装；
- 装上的是新版本，旧版本留在历史里，不满意可以「换回上一版」。

别人导入的插件包（source=imported）不进这个回路：没有生成模型，也没法让 AI 改。

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示「还没给插件工坊配模型」 | 点「配置生成模型」，选强模型并填 API Key |
| 提示「自动检查没通过」 | 把需求说得更具体一点，或换更强的模型再试一次 |
| 提示「连不上生成模型」 | 检查 API Key、网络、模型名对不对（跟 AI 大脑用的是两套配置） |
| 生成很慢 | 生成要跑两三次模型调用（方案 → 代码 → 检查），一般 1~3 分钟 |


## 无头端（Linux 服务器）怎么用

服务器上没有图形界面，工坊有后台接口，控制台里也已经有「插件工坊」这一页：

| 接口 | 干什么 |
|---|---|
| `GET /api/workshop/status` | 看能不能生成、用的哪家模型、已经装了哪些插件 |
| `PUT /api/workshop/config` | 配生成模型：`{"provider": "deepseek", "api_key": "sk-...", "model": "deepseek-chat"}` |
| `POST /api/workshop/build` | 生成：`{"need": "群里签到记金币"}`（返回方案、检查结果和 `build_id`） |
| `POST /api/workshop/install` | 安装：`{"build_id": "上一步给的"}`（只认刚生成的那一份，防止装来路不明的文件） |
| `GET /api/workshop/history?pack_id=xxx` | 看这个插件的历史版本 |
| `POST /api/workshop/rollback` | 换回上一版：`{"id": "插件id"}` |
| `POST /api/workshop/uninstall` | 卸载：`{"id": "插件id"}` |
| `GET /api/workshop/errors` | 看哪些插件跑出过错（界面上的「让 AI 修一版」靠它亮按钮） |
| `POST /api/workshop/repair` | 按真实报错让 AI 改一版：`{"id": "插件id"}`（同样返回 `build_id`，走 install 装） |
| `POST /api/workshop/export` | 导出 zip：`{"id": "插件id"}` |
| `POST /api/workshop/import` | 导入插件包：`{"zip_b64": "<zip 的 base64>", "filename": "x.zip"}` |
| `POST /api/workshop/upload` | 上传到官网等审核：`{"id": "插件id", "note": "给站长的话"}` |
| `GET /api/workshop/submissions` | 我上传过的插件（含审核状态、驳回原因） |
| `POST /api/workshop/submissions/withdraw` | 撤回还没审的投稿：`{"id": 12}` |
| `GET /api/workshop/account` | 当前有没有登录星群账号（上传要用） |
| `POST /api/workshop/account` | 登录星群账号：`{"email": "...", "password": "..."}` |
| `POST /api/workshop/account/logout` | 退出星群账号 |

都要登录（请求头 `Authorization: Bearer <登录 token>`）。装完/回滚/卸载要让机器人重启才生效。
